Original to this project (not copied from upstream): `vendor/gtk4.css`, `vendor/login.css`,
`vendor/apps/zsh-theme.zsh`, `tools/`, `tests/`, `extension/`, and the pixel cursor theme
generated by `tools/cursor.py`.

Palette and typography are taken from upstream `Theme.qml`. Upstream runtime-generated
Kitty styling is reimplemented as a standalone configuration; no Hyprland, SDDM, Fish or
Quickshell startup code is executed or installed. Folder icons, the pixel cursor, dot-grid wallpaper
and GNOME extension are new adaptation work. GTK3 imports the user's system Yaru theme; Yaru (GPL-3.0/CC-BY-SA) and
Papirus (GPL-3.0) are dependencies, not redistributed here.

`vendor/fonts/OFL.txt`: Doto (The Doto Project Authors), Space Mono (The Space Mono Project
